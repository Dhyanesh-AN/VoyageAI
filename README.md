##  Overview

Planning a trip usually means bouncing between flight search engines, hotel sites, review pages, and a half-finished spreadsheet. **Voyage AI** collapses that entire workflow into a single conversation.

Under the hood, a graph of specialized agents — each responsible for one part of the trip — works together to research, reason, and assemble a coherent plan:

- ✈️ **Flight Agent** — sources flight options via AviationStack
- 🏨 **Hotel Agent** — researches accommodation using Tavily search
- 🗓️ **Itinerary Agent** — builds a structured, day-by-day plan
- 🧩 **Response Agent** — synthesizes everything into a clean, final answer

All of it is orchestrated through a **LangGraph** workflow, served over **FastAPI**.

| | |
|---|---|
| ✈️ **Flight Research** | Real-time flight data via the AviationStack API |
| 🏨 **Hotel Discovery** | Accommodation suggestions powered by Tavily search |
| 🧠 **Multi-Agent Orchestration** | LangGraph-driven coordination between specialized agents |
| 📝 **Structured Itineraries** | Clean, day-by-day travel plans — not walls of text |
| 🌐 **Web Interface** | FastAPI backend with a lightweight built-in frontend |
| 💾 **Persistent Conversations** | Session/state persistence via PostgreSQL |

- **Orchestration:** LangGraph + LangChain
- **LLM Provider:** Groq

## 🔐 Environment Variables

Create a `.env` file in the project root:


## How the Workflow Works

```text
User Request
     │
     ▼
✈️  Flight Agent  ──► gathers flight options
     │
     ▼
🏨  Hotel Agent   ──► searches accommodation
     │
     ▼
🗓️  Itinerary Agent ──► builds the day-by-day plan
     │
     ▼
🧩  Response Agent ──► formats the final, polished result
     │
     ▼
   Final Travel Plan
```

1. The user submits a travel request in natural language.
2. The **flight agent** gathers relevant flight information.
3. The **hotel agent** searches for accommodation suggestions.
4. The **itinerary agent** assembles a practical day-by-day plan.
5. The **response agent** formats everything into a polished final answer.
